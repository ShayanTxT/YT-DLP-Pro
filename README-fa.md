## ⭐ چرا YT-DLP Pro؟

بیشتر دانلودرهای یوتیوب فقط یک رابط ساده روی yt-dlp هستند: لینک را می‌چسبانی، کیفیت را انتخاب می‌کنی و منتظر می‌مانی. YT-DLP Pro کارهایی را انجام می‌دهد که بقیه انجام نمی‌دهند:

| قابلیت | دانلودرهای معمول | **YT-DLP Pro** |
|---|:---:|:---:|
| شروع دانلود با کپی کردن لینک (Clipboard Watch) | ❌ | ✅ |
| دانلود فقط بازه‌ای از ویدیو (مثلاً `0:32–0:41`) و تبدیل به GIF | ❌ | ✅ |
| دیدن حجم هر کیفیت قبل از دانلود | ❌ | ✅ |
| انتخاب خودکار «بهترین کیفیت زیر ۱۰۰ مگابایت» | ❌ | ✅ |
| حذف بخش‌های اسپانسر و معرفی (SponsorBlock) | ❌ | ✅ |
| دنبال کردن کانال‌ها و دانلود فقط ویدیوهای **جدید** | ❌ | ✅ |
| دانلود با جستجوی متن، بدون نیاز به لینک | ❌ | ✅ |
| دانلود موازی چند ویدیو همزمان | ⚠️ محدود | ✅ |
| کیفیت‌های 4K تا 144p، MP3 با کاور، پلی‌لیست، زیرنویس | ✅ | ✅ |

## ✨ قابلیت‌های اصلی

### 📋 Clipboard Watch — دانلود خودکار
یک بار اجرا کن و به مرور ادامه بده. هر لینک ویدیویی که کپی کنی (یوتیوب، اینستاگرام، تیک‌تاک، X، Vimeo و …) در پس‌زمینه دانلود می‌شود.

```powershell
ytd --watch            # فقط لینک کپی کن
ytd --watch -a         # همه را به صورت MP3 دانلود کن
```

### ✂️ ساخت کلیپ و GIF
فقط بخش موردنیازت را دانلود کن:

```powershell
ytd <URL> --clip 0:32-0:41            # کلیپ MP4 نُه‌ثانیه‌ای
ytd <URL> --clip 1:02-1:07 --gif      # همان لحظه به صورت GIF بهینه
ytd <URL> --clip 45-90 -a             # بخشی از صدا به صورت MP3
```

### 📏 پیش‌نمایش حجم و سقف حجم
دیگر «آخ، این ۴K سه گیگ شد!» نداریم. منوی کیفیت حجم تقریبی هر گزینه را نشان می‌دهد و حالت هوشمند خودش انتخاب می‌کند:

```powershell
ytd <URL> --max-size 100M    # بهترین کیفیتی که زیر ۱۰۰ مگابایت جا می‌شود
ytd <URL> --max-size 1.5G
```

### 🚫 حذف اسپانسر
بخش‌های تبلیغاتی و تعاملی را که جامعه کاربران علامت زده‌اند، از خود فایل حذف می‌کند:

```powershell
ytd <URL> --clean                       # اسپانسر + تبلیغ خود سازنده + تعامل
ytd <URL> --sb sponsor,intro,outro      # انتخاب دسته‌ها به دلخواه
```

### 🔔 اشتراک کانال
یک بار کانال را دنبال کن؛ با یک دستور فقط ویدیوهای جدید دانلود می‌شوند. سابقه دانلود مانع از دوباره‌کاری می‌شود.

```powershell
ytd --subscribe https://www.youtube.com/@SomeChannel --name "SomeChannel"
ytd --sync          # فقط ویدیوهای جدید همه اشتراک‌ها
```

### 🔎 جستجو و دانلود
```powershell
ytd "lofi hip hop radio"        # اولین نتیجه جستجو را دانلود می‌کند
ytd --search "python tutorial" -q 720
```

### ⚡ موتور موازی
چند ویدیو هم‌زمان (`--workers 4`)، دانلود موازی قطعات هر فایل، ادامه دانلود بعد از قطع شدن، و پشتیبانی اختیاری از [aria2c](https://aria2.github.io/).

همچنین: کنترل کیفیت از 4K تا 144p، MP3 با کاور و متادیتا، پلی‌لیست با بازه (`--items 1:10`)، زیرنویس، تقسیم فصل‌ها برای آلبوم و پادکست، دانلود دسته‌ای از فایل (`--file links.txt`)، تاریخچه دانلود، و استفاده از کوکی مرورگر برای ویدیوهای محدود. روی بیش از ۱۰۰۰ سایت پشتیبانی‌شده توسط yt-dlp کار می‌کند، نه فقط یوتیوب.

## 🖥️ سیستم‌عامل‌های پشتیبانی‌شده

| سیستم‌عامل | وضعیت | نحوه نصب |
|---|---|---|
| Windows 10 / 11 | ✅ پشتیبانی‌شده (هدف اصلی) | `install.bat`، فایل EXE مستقل یا pip |
| Linux (Ubuntu، Debian، Mint، Fedora، Arch — x86_64) | ✅ پشتیبانی‌شده | `./install.sh`، فایل اجرایی مستقل یا pip |
| macOS | 🧪 تجربی — رسماً تست نشده | pip یا سورس |

## 📦 نصب

> **پیش‌نیاز:** ویندوز ۱۰ یا ۱۱. برای ادغام کیفیت HD، MP3 و GIF به [FFmpeg](https://ffmpeg.org/) نیاز است. نصب‌کننده و دستورهای زیر آن را هم نصب می‌کنند.

### روش الف — فایل اجرایی (ساده‌ترین، بدون نیاز به Python)
1. فایل `YT-DLP-Pro.exe` را از بخش [**Releases**](../../releases) دانلود کن.
2. یک بار FFmpeg را نصب کن: `winget install Gyan.FFmpeg`
3. اجرا کن: `YT-DLP-Pro.exe <link>` یا با دابل‌کلیک منو را باز کن.

> 💡 نام فایل را به `ytd.exe` تغییر بده و در پوشه‌ای که در PATH است (مثلاً `C:\Tools`) قرار بده تا دستور `ytd` در همه ترمینال‌ها فعال شود.

### روش ب — نصب‌کننده یک‌کلیکی (از سورس)
1. مخزن را دانلود یا clone کن.
2. فایل **`install.bat`** را اجرا کن. Python، FFmpeg و کتابخانه‌ها نصب می‌شوند، محیط مجازی ساخته می‌شود و میانبر روی دسکتاپ ایجاد می‌شود.
3. برنامه را از روی میانبر یا با `YT-DLP-Pro.bat <link>` اجرا کن.

### روش ج — pip
```powershell
git clone https://github.com/ShayanTxT/ytd-pro.git
cd ytd-pro
pip install .
ytd <link>
```

### روش د — Python مستقیم
```powershell
pip install -r requirements.txt
python yt_downloader.py <link>
```

### لینوکس

```bash
git clone https://github.com/ShayanTxT/ytd-pro.git
cd ytd-pro
./install.sh            # ساخت venv و نصب کتابخانه‌ها + دستورهای `ytd` و `YT-DLP` + میانبر منو
ytd https://youtu.be/xxxxxxxxxxx
```

- به **Python 3.10 یا جدیدتر** نیاز دارد. در Debian/Ubuntu اگر نصب‌کننده خواست، `python3-venv` را هم نصب کن.
- برای ادغام HD، MP3، کلیپ و GIF، **ffmpeg** نصب کن: `sudo apt install ffmpeg` (Fedora: `sudo dnf install ffmpeg`، Arch: `sudo pacman -S ffmpeg`).
- Clipboard Watch به `xclip` (X11) یا `wl-clipboard` (Wayland) و همچنین `pip install pyperclip` نیاز دارد.
- برای حذف: `./install.sh --uninstall` (دانلودها و تنظیماتت حفظ می‌شوند).
- فایل اجرایی مستقل: `ytd-linux-x86_64` را از بخش [Releases](../../releases) دانلود کن، `chmod +x` بزن و اجرا کن. این فایل روی Ubuntu 22.04 ساخته شده و روی توزیع‌هایی با glibc نسخه 2.35 یا جدیدتر اجرا می‌شود.
- در Ubuntu 23.04 به بعد با pip از `pipx install .` استفاده کن. دستور `pip install .` در همه سیستم‌عامل‌ها دستور `ytd` را می‌سازد.

## 🖥️ رابط تمام‌صفحه ترمینال

در هر ترمینالی (CMD، PowerShell یا Windows Terminal) فقط **`YT-DLP`** را تایپ کن تا رابط تمام‌صفحه باز شود:

- **Download (دانلود)** — لینک یا عبارت جستجو را بچسبان، کیفیت و MP3/MP4 را انتخاب کن، کلیپ، سقف حجم، حذف اسپانسر یا زیرنویس را تنظیم کن و نوار پیشرفت زنده را ببین.
- **Watch (واچ)** — Clipboard Watch را روشن یا خاموش کن؛ لینک‌های کپی‌شده در صف قرار می‌گیرند و یکی‌یکی دانلود می‌شوند.
- **Subscriptions (اشتراک‌ها)** — کانال دنبال کن، ویدیوهای جدید را همگام کن یا حذف کن.
- **History (تاریخچه)** — همه دانلودهای قبلی را ببین.
- **Settings (تنظیمات)** — پوشه دانلود، تعداد قطعات و ویدیوهای موازی و حذف اسپانسر پیش‌فرض.

کلیدهای میان‌بر: `Ctrl+D` رفتن به کادر لینک · `Ctrl+W` روشن/خاموش کردن Clipboard Watch · `Q` خروج.
اگر منوی متنی قدیمی را ترجیح می‌دهی: `ytd --classic`.

> `install.bat` دستور `YT-DLP` را خودکار ثبت می‌کند. برای فایل EXE مستقل، آن را در پوشه‌ای که در PATH است با نام `YT-DLP.exe` قرار بده.

## 🚀 شروع سریع

```powershell
ytd                                  # منوی تعاملی
ytd https://youtu.be/xxxxxxxxxxx     # دانلود فوری با بهترین کیفیت
ytd <URL> -q 720                     # ۷۲۰p
ytd <URL> -a                         # فقط MP3 (320 kbps با کاور)
ytd <PLAYLIST_URL> -p                # کل پلی‌لیست، شماره‌گذاری‌شده
ytd <URL> -s                         # با زیرنویس انگلیسی/فارسی
ytd --file links.txt --workers 4     # دانلود دسته‌ای، ۴ تا هم‌زمان
```

### منوی تعاملی
```
What do you want to do?
   1  دانلود سریع (بهترین کیفیت)
   2  دانلود با انتخاب کیفیت و پیش‌نمایش حجم
   3  فقط صدا (MP3)
   4  دانلود پلی‌لیست
   5  ساخت کلیپ / GIF
   6  جستجو و دانلود (بدون لینک)
   7  Clipboard Watch (کپی لینک ← دانلود خودکار)
   8  اشتراک‌ها (دریافت ویدیوهای جدید)
   9  تاریخچه دانلود
  10  باز کردن پوشه دانلودها
  11  تنظیمات
   0  خروج
```

پوشه پیش‌فرض دانلودها `C:\Users\<you>\Downloads\YouTube` است و از بخش تنظیمات قابل تغییر است. پلی‌لیست‌ها پوشه شماره‌دار خودشان را دارند.

### همه گزینه‌های خط فرمان

| گزینه | توضیح |
|---|---|
| `-a`, `--audio` | فقط صدا — MP3 با ۳۲۰ kbps و کاور و متادیتا |
| `-q` | کیفیت: `best` `2160` `1440` `1080` `720` `480` `360` `240` `144` |
| `--max-size 100M` | بهترین کیفیت زیر سقف حجم (`K`/`M`/`G`) |
| `-f` | انتخاب فرمت خام yt-dlp، مثلاً `-f 137+140` |
| `--list-formats` | نمایش همه فرمت‌های موجود یک ویدیو |
| `-p`, `--playlist` | دانلود کل پلی‌لیست |
| `--items 1:10` | بازه‌ای از آیتم‌های پلی‌لیست |
| `--file links.txt` | دانلود دسته‌ای (یک لینک در هر خط) |
| `--workers N` | دانلود همزمان N ویدیو |
| `--archive` | رد شدن از ویدیوهای قبلاً دانلودشده (ماندگار) |
| `-s`, `--subs` | زیرنویس کنار ویدیو (انگلیسی/فارسی) |
| `--embed-subs` | جاسازی زیرنویس داخل فایل |
| `--clip 0:32-0:41` | فقط دانلود همان بازه زمانی |
| `--gif` | تبدیل نتیجه (یا کلیپ) به GIF |
| `--split-chapters` | یک فایل برای هر فصل (آلبوم، پادکست) |
| `-C`, `--clean` | حذف بخش‌های اسپانسر و تبلیغ (SponsorBlock) |
| `--sb sponsor,intro` | انتخاب دسته‌های دلخواه SponsorBlock |
| `--watch` | حالت Clipboard Watch |
| `--search "..."` | جستجو در یوتیوب و دانلود اولین نتیجه |
| `--subscribe <URL>` | دنبال کردن کانال یا پلی‌لیست |
| `--sync` | دانلود ویدیوهای جدید همه اشتراک‌ها |
| `--subscriptions` / `--unsubscribe` | مدیریت اشتراک‌ها |
| `--browser-cookies chrome` | برای ویدیوهای سنی‌محدود یا ویژه اعضا |
| `-o` | پوشه خروجی |
| `--history` | نمایش تاریخچه دانلود |
| `--classic` | استفاده از منوی متنی قدیمی به‌جای رابط تمام‌صفحه |
| `--update` | به‌روزرسانی موتور yt-dlp (بیشتر خطاها را برطرف می‌کند) |
| `-h`, `-v` | راهنما / نسخه |

## 🛠️ عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| خطاهای تصادفی دانلود | در بیشتر موارد: `ytd --update` (یوتیوب دائم تغییر می‌کند و yt-dlp باید به‌روز باشد) |
| «ffmpeg not found» یا ویدیو بدون صدا | `winget install Gyan.FFmpeg` و سپس بستن و باز کردن ترمینال |
| خطای سن‌محدودیت یا «sign in» | `ytd <URL> --browser-cookies chrome` (باید در همان مرورگر وارد یوتیوب شده باشی) |
| قطع شدن دانلود | همان دستور را دوباره اجرا کن؛ از جایی که مانده ادامه می‌دهد |
| دانلود کند | در تنظیمات تعداد قطعات موازی را بالا ببر یا aria2c را فعال کن (`winget install aria2.aria2`) |
| Clipboard Watch کار نمی‌کند | `pip install pyperclip` را اجرا کن؛ در ویندوز نیازی به آن نیست |
| Clipboard Watch روی لینوکس کار نمی‌کند | `xclip` (X11) یا `wl-clipboard` (Wayland) را نصب کن و `pip install pyperclip` را اجرا کن |

## 🏗️ ساخت فایل اجرایی

فایل **`build_exe.bat`** را اجرا کن؛ خروجی `dist\YT-DLP-Pro.exe` است، یک فایل مستقل. با push کردن تگ نسخه (`git tag v2.0.0 && git push --tags`) workflow داخلی GitHub Actions هم فعال می‌شود، فایل را می‌سازد و به Release اضافه می‌کند.

## 📁 ساختار پروژه

```
ytd-pro/
├── yt_downloader.py        ← موتور اصلی + منوی متنی/CLI (یک فایل)
├── ytd_tui.py              ← رابط تمام‌صفحه ترمینال (Textual)
├── tests/test_core.py      ← تست‌های واحد و رابط (pytest)
├── install.sh              ← نصب‌کننده لینوکس (و --uninstall)
├── build.sh                ← ساخت فایل اجرایی تک‌فایل برای لینوکس
├── install.bat             ← نصب‌کننده یک‌کلیکی ویندوز
├── YT-DLP-Pro.bat          ← لانچر ویندوز
├── build_exe.bat           ← ساخت EXE در ویندوز
├── pyproject.toml          ← بسته‌بندی pip (دستور `ytd`)
├── requirements.txt
├── links.example.txt       ← نمونه دانلود دسته‌ای
├── assets/                 ← بنر و اسکرین‌شات‌ها
└── .github/                ← CI، workflow ریلیز، قالب Issue
```

تنظیمات، تاریخچه، اشتراک‌ها و آرشیو دانلود در پوشه `~/.ytdpro/` ذخیره می‌شوند.
